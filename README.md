## 🎯 Contexto do Projeto

Este projeto tem como objetivo explorar o uso da Inteligência Artificial como ferramenta de apoio aos estudos.

O tema escolhido para o caderno temático foi:

> **Educação Financeira para Iniciantes**

O conteúdo aborda conceitos importantes como organização financeira, juros simples, juros compostos, investimentos, rentabilidade, risco e liquidez.

---

## 🎯 Objetivos de Estudo

Os principais objetivos deste projeto são:

- Entender os conceitos básicos de educação financeira;
- Compreender a diferença entre poupar e investir;
- Aprender como funcionam juros simples e compostos;
- Entender risco, retorno, rentabilidade e liquidez;
- Utilizar o NotebookLM para estudar conteúdos;
- Criar prompts mais eficientes;
- Utilizar fontes confiáveis para verificar informações.

# 🤖 Engenharia de Prompts

Durante o projeto foram testadas diferentes maneiras de fazer perguntas para a Inteligência Artificial.

## Prompt 1 — Simples

```text
Explique o que são juros compostos.
```

### Resultado

A resposta apresentou uma explicação básica sobre juros compostos.

Porém, percebi que um prompt muito simples pode gerar uma resposta mais genérica.

---

## Prompt 2 — Mais detalhado

```text
Explique juros compostos para um estudante iniciante,
utilizando linguagem simples e um exemplo com R$ 1.000.
```

### Resultado

A resposta ficou mais fácil de entender porque foi solicitado:

- nível de conhecimento;
- linguagem simples;
- exemplo prático.

---

## Prompt 3 — Utilizando as fontes

```text
Utilizando somente as fontes deste caderno,
explique juros compostos, apresente um exemplo
e indique as referências utilizadas.
```

### Resultado

Esse prompt apresentou uma resposta mais direcionada aos materiais utilizados no projeto.

Também facilitou a verificação das informações.

---

## Prompt 4 — Criando exercícios

```text
Crie cinco perguntas sobre educação financeira
com base nas fontes deste caderno
e apresente o gabarito no final.
```

### Resultado

Esse teste mostrou que a IA também pode ser utilizada para criar exercícios e ajudar na revisão do conteúdo.

# 🩹 Cicatrizes e Troubleshooting

Durante o desenvolvimento do projeto encontrei algumas dificuldades.

### Problema 1

Prompts muito pequenos geravam respostas genéricas.

### Solução

Passei a fornecer mais informações no prompt.

---

### Problema 2

Algumas explicações eram mais difíceis para um iniciante.

### Solução

Adicionei ao prompt:

```text
Explique como se estivesse ensinando um estudante iniciante.
```

### Problema 3

Era necessário verificar de onde as informações estavam vindo.

### Solução

Passei a utilizar:

```text
Responda utilizando somente as fontes deste caderno
e indique as referências utilizadas.
```

# 📖 Miniguia de Educação Financeira

## 💰 Educação Financeira

Educação financeira envolve conhecimentos e hábitos que ajudam uma pessoa a organizar melhor seus recursos e tomar decisões financeiras mais conscientes.

---

## 💵 Poupar x Investir

### Poupar

Poupar significa guardar uma parte do dinheiro para utilizar no futuro.

### Investir

Investir significa aplicar dinheiro buscando determinado objetivo financeiro, considerando fatores como:

- risco;
- prazo;
- rentabilidade;
- liquidez.

---

# 📈 Juros Simples

Nos juros simples, os juros são calculados utilizando como base o capital inicial.

### Fórmula

```text
J = C × i × t
```

Onde:

| Símbolo | Significado |
|---|---|
| J | Juros |
| C | Capital |
| i | Taxa de juros |
| t | Tempo |

---

# 📊 Juros Compostos

Nos juros compostos, os rendimentos acumulados passam a fazer parte do cálculo dos próximos períodos.

Por isso, eles são conhecidos como:

> **Juros sobre juros**

### Fórmula

```text
M = C × (1 + i)^t
```

Onde:

| Símbolo | Significado |
|---|---|
| M | Montante |
| C | Capital |
| i | Taxa |
| t | Tempo |

---

## 🧮 Exemplo

Imagine um investimento de:

```text
Capital = R$ 1.000
Taxa = 10% ao ano
Tempo = 2 anos
```

Depois do primeiro ano:

```text
R$ 1.000 + 10% = R$ 1.100
```

Depois do segundo ano:

```text
R$ 1.100 + 10% = R$ 1.210
```

### Resultado

```text
Valor inicial: R$ 1.000
Valor final:   R$ 1.210
Rendimento:    R$ 210
```

---

# ⚠️ Risco e Retorno

Todo investimento possui características e riscos.

Antes de investir é importante analisar:

- objetivo;
- prazo;
- risco;
- rentabilidade;
- liquidez;
- características do investimento.

---

# 📕 Glossário

| Conceito | Significado |
|---|---|
| Capital | Valor inicial utilizado em uma operação financeira |
| Juros | Valor relacionado ao uso do dinheiro durante determinado período |
| Juros Compostos | Juros calculados sobre o valor acumulado |
| Investimento | Aplicação de recursos buscando um objetivo financeiro |
| Rentabilidade | Resultado obtido por um investimento |
| Risco | Possibilidade de o resultado ser diferente do esperado |
| Liquidez | Facilidade de transformar um investimento em dinheiro |
| Diversificação | Distribuição dos recursos entre diferentes investimentos |


```text

deste caderno e apresente o gabarito no final.
```
